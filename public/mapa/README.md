# Mapas canônicos

Arquivos esperados pela interface:
- `primeiro-andar-limpo.webp`
- `primeiro-andar-numerado.webp`
- `andar-superior-limpo.webp`

As posições dos hotspots permanecem sem coordenadas fixas até serem ajustadas pelo mestre na própria tela do mapa. A versão local enviada em **Imagens / Backup** sempre pode sobrescrever o fallback estático sem alterar o cânone.
